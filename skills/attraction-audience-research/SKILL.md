# 异性吸引力数据研究

先查用户已有研究目录、冻结规则、最新有效证据和可用读取工具；复用采集成果，避免逐次重新读取整个数据集。工具代码属于 `attraction-data-lab` 仓库，不能假设它随 Skill 安装：在用户提供的仓库目录运行命令；找不到时获取该仓库或询问已有位置，不能猜本机路径。仓库地址为 https://github.com/yiyan129600/attraction-data-lab 。

按当前任务读对应参考：
- 建立研究、扩样、控制成本：[research.md](references/research.md)。
- 接入已有 MCP、浏览器或手工证据：[collection.md](references/collection.md)。
- 内容与画像分析、报告、反例：[analysis.md](references/analysis.md)。
- 归档、导出与社区贡献：[community.md](references/community.md)。

## 完成一个研究闭环

1. 冻结研究问题、主题、筛选口径、正反例配额、目标采集深度、预算与停止条件；从已有信息形成默认方案，不要求用户填模板。目标“30 篇正例、每帖尽量 100 条评论”是容量目标，不是事实保证。
2. 先筛平台评论数、精确粉丝数与作者证据，再深入核对。每个候选保留纳入、排除或未知原因。检索失败与未达配额如实记录。
3. 每批证据落盘、去重、导入、检查点后继续；汇报新增有效样本、缓存命中与缺口，避免把原始评论反复送入模型。确定性统计交给脚本。
4. 从本地数据库生成分析与 HTML。保留反例；区分实际评论条数、一级/回复/作者回复和去重画像人数。所有推荐附来源、分母和局限。
5. 用户要求分享时先区分格式：允许保留公开帖子来源的社区v1用 `community.py export`；要求不含帖子身份、标题和原声的标签统计用 `scripts/export_tag_aggregates.py`（契约见仓库 `docs/TAG-METHODS.md`），再用 `scripts/build_revision_report.py` 生成聚合HTML。两种格式分别校验，不能互相替代。原始数据库含研究密钥，不能作为公共数据库上传。仅在用户授权的仓库发布；Skill 本身不授予对外发布权限。

## 不可丢失的统计语义

性别与年龄仅用明确公开披露或授权聚合资料；头像、昵称、外貌、职业不是证据。未知保留未知，年龄未知不等于成年。公开兴趣表达与推测对他人的偏好分开。不要建立可联系的女性个人名单。

U 是已加载且稳定去重的外部一级评论者；N 是实际核对人数；K 是明确性别人数；F 是明确女性人数。同时给 F/K、K/N、F/N，不将局部样本外推成整帖人数。排除明确未成年后的 adult_target 仍含年龄未知者，必须标注。

公开评论不证明实际私聊；只有用户授权的自有账号聚合记录才能分析私聊结果。归因未知与可归因结果分开。

本地原始证据、失败记录和历史快照保留；共享包是它们的派生产物。现有登录态不能假设跨浏览器或 MCP 共享。遇到登录、验证码或访问拒绝，停止相关采集，继续离线工作，不更换身份绕过。
