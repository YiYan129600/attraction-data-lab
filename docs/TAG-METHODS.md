## 双轨研究与判定

比较轨按预定主题和固定规则取样，不先按评论量或女性比例选择；参考轨专门保留高评论案例，服务表达方式研究。两轨分别报告，历史高评论定向采样保持原口径；不合并成全平台成功率。主题覆盖外貌/穿搭、健身、户外、球类、音乐、做饭、居家、宠物、旅行、工作/手艺、文化兴趣、车辆等12个方向。

本轮初查先固定前8位外部一级不同评论用户，再核查公开明确证据。N是实际核对且排除明确未成年后的不同人数，K为其中性别明确人数，F为明确女性人数。N≥8、K/N≥60%、F/K>50%记女性参与正向；同样人数/覆盖门槛下F/K≤50%记对照。人数、披露或证据不足保留未知。低评论、未成年排除、内容不合格与女性对照是不同维度。年龄未知不当作已成年；不通过头像、昵称推断性别或年龄。

评论数用于讨论活跃程度；女性参与初查用于描述已核查且明确披露者；公开表达、私人联系意图和实际主动私聊分开。当前没有统一曝光、私聊结果或长期追踪，不计算转化率，不推出稳定择偶偏好。公开聚合文件不含任何逐人画像。

## 如何计算

标签只来自实际正文和平台标签：NFKC规范化、去开头井号与边缘空白、大小写折叠；不自动合并近义词。`长发男`、`长发男生`、`男生长发`分别统计。搜索词、人工主题词和评论里的词不替代平台标签。

同一范围内按标签有/无分组。每个指标各用自己的精确样本分母，展示有效量、缺失、作者数、均值、中位数、四分位和极值。缩写展示估算不进入精确均值，缺失不补零。点赞保留全部记录及来源明确两套指标；来源明确点赞只接受已明确记录的搜索卡片点赞来源，不把评论点赞或待核对数字混入。

同时查看10%两端截尾均值（至少10个有效值时）、两组各移除一个最大值后的均值差，以及同来源+同主题的共同分层差。分层要求有/无标签各≥2篇，按层总样本数加权；未知/无法映射主题不入层，并报告缺口。任一组精确样本少于5篇标为不足。敏感性检查不删除原数据，也不是因果校正。聚合发布保留共同层汇总和覆盖量，不携带自由文本层名。

同帖多观察按可追溯的最新非缺失记录合并，保留时间差异；重复作者、标签共现、抽样来源和快照时点仍是混杂因素。公开聚合可以复算表内均值差，因不发布逐帖资料，外部无法重建所有原始证据；完整复现需研究者自己的已授权本地输入。

## 可复用工具

公开能力由私有构建器的确定性统计与报告层整理而来：`xhs_research/tag_analysis.py`、`scripts/build_tag_data.py`、`scripts/export_tag_aggregates.py`、`scripts/build_revision_report.py`。没有复制私人输入路径、逐帖特判、原声页面或原始证据适配器。路径全部通过CLI传入，无网络和第三方Python依赖。

离线完整模拟流程（在仓库根目录，Python 3.10+）：

```sh
python scripts/build_tag_data.py --input examples/tag-posts.synthetic.json --output data/private/tag-demo/statistics.json
python scripts/export_tag_aggregates.py --statistics data/private/tag-demo/statistics.json --audit examples/tag-audit.synthetic.json --dataset synthetic-tag-demo --output exports/tag-demo/aggregates.json
python scripts/build_revision_report.py --input exports/tag-demo/aggregates.json --output exports/tag-demo/report.html
```

模拟输入/输出保留`source_mode=synthetic`，不并入真实统计。输入`posts`的最小契约以模拟文件为准：`tags`已规范化且来自实际标签；`tag_known`表示标签证据已知；指标是非负精确整数或null；`metric_evidence`的`precision`决定是否精确；`likes_verified`还必须有`#search.likes_raw`明确来源标记。`creator_id`仅在本地计作者数，永不导出。`verified_lowfan_eligible`需先依据真实证据判定，不由统计脚本猜测；`balanced_pool`是已冻结的研究成员；`topic_stratum`是已映射主题，未知为null。统计工具不代替采集与资格核验。

真实发布命令使用自己的私有输入：

```sh
python scripts/build_tag_data.py --input data/private/my-study/combined-data.json --output data/private/my-study/statistics.json
python scripts/export_tag_aggregates.py --statistics data/private/my-study/statistics.json --audit data/private/my-study/audit.json --dataset my-study-v1 --output aggregates/my-study-v1.json
python scripts/build_revision_report.py --input aggregates/my-study-v1.json --output aggregates/my-study-v1.html
```

审计计数契约见`examples/tag-audit.synthetic.json`，应由自己的证据统计生成，不复制本轮数字。保留CLI输入位置本身不会导致路径写入公开包；导出器从白名单新建结构。`templates/public-tag-labels.json`是人工审核通用词目录，新词未审核默认匿名。公开校验拒绝额外字段、非有限数、错误分母和未经审核词。

## 两种交换格式

`aggregates/*.json`的`public-tag-aggregates-v1`是本次严格聚合格式，不含帖子来源链接、身份字段、标题、原声、图片或本地路径。它与既有`contributions/*.json`的社区v1逐帖来源统计包不同；此前获授权公开的来源包保持原状。不要用`community.py export`替代本次聚合导出，也不要把聚合包交给社区v1合并器。

Collector V2提供预算、缓存、回放、检查点和REST接口适配；安装使用见[说明](collector-v2/USAGE.md)。本轮只公开代码和离线证据，未运行平台采集、未确认实时服务可用、未实测站点吞吐。2026-10-14的服务故障记录仅为历史证据。
